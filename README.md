# 鸿蒙权限向导

面向 HarmonyOS 开发者的静态权限查询工具。开发者选择应用功能，网站整理对应权限，区分直接声明和官网申请，并在权限下补充官方提供的替代实现方式及来源链接。

## 使用

[在线访问](https://normanfxxkingrockwell.github.io/harmonyOS-ACL-Permission-Check/)

本地使用 Node.js 20 或更高版本，无需安装依赖：

```powershell
npm run dev
```

打开 http://127.0.0.1:4173 。开发服务器绑定本机，可用环境变量 `PORT` 更换端口。

```powershell
npm test
npm run build
```

构建结果位于 `dist/`，使用相对资源路径，支持 GitHub Pages 项目子目录及其他静态托管服务。

## 功能

- 41 个常见应用场景，包含录像是否录音、位置精度、后台定位和联系人写入等功能选项。
- 290 项未废弃权限，按 13 个业务领域检索和选择；资料库支持蓝牙、网络、DLP、加密等通俗关键词、同义词与权限名查询。
- 所选权限保留在清单中；有官方明确声明依赖的权限自动补齐，并说明对应关系。
- 按官方五类权限分区，展示哪些直接声明、哪些通过官网申请；授权方式单独列出。
- 官方设备、用途、资格与版本信息作为权限资料展示，网站不据此判断用户资格或拦截所选权限。
- 根据所选权限及官方开放版本信息，自动计算权限的最低 API 要求。
- 官方提供选择器、保存控件等替代方案时，在对应权限下说明做法并附官方链接，开发者自行选择实现方式。
- 详情展示官方权限正文快照和原文链接。
- 配置按 HAP 声明、独立二进制权限和带额外 `value` 的权限分别输出；特殊配置类型保持独立。
- `module.json5` 片段和授权用途字符串资源默认折叠展示。`EntryAbility` 是生成片段中的组件名称占位值。
- 导出 JSON 清单，包含所选权限、来源、申请方式、版本信息与分类配置。
- 浏览器本地保存选择；“重新开始”清空当前方案。支持手机与宽屏布局。

应用分发类型、运行设备等选项用于展示与计算权限资料。开发者主体和元服务等官方条件属于条目说明；没有额外的手动确认步骤。MDM 管理权限也作为普通查询条目按需选择。

## 发布

`.github/workflows/pages.yml` 在 `main` 推送和手动触发时运行测试、构建并部署 GitHub Pages。PR 执行测试与构建。仓库 Pages 的发布来源为 GitHub Actions。

构建为整套资源和数据生成版本路径，使页面加载同一版本的模块。

## 数据与文件

权限数据由人工阅读官网后维护。项目没有网站抓取脚本、定时扫描或自动更新权限任务。

| 文件 | 内容 |
|---|---|
| `data/permissions.json` | 五类官方权限列表的静态正文、元数据和来源链接 |
| `src/rules.js` | 场景选择、权限整理和分类配置输出 |
| `src/search-index.js`、`src/search-keywords-a.js`、`src/search-keywords-b.js` | 全量权限关键词、同义词与检索排序 |
| `src/domains.js` | 290 项权限的业务领域分类 |
| `src/constraints.js` | 官方权限起始版本、开放版本及设备版本信息 |
| `src/official-info.js` | 官方资料提取与配置类型分类 |
| `src/relations.js` | 官方明确的声明依赖和授权流程说明 |
| `src/permission-alternatives.js` | 官方替代实现方式及链接 |
| `src/copy-catalog-a.js`、`src/copy-catalog-b.js` | 通俗功能问题与场景例子 |
| `src/coverage.js` | 完整权限选择页 |
| `src/results.js` | 分类权限清单、官方说明和配置展示 |
| `src/app.js`、`src/style.css` | 页面交互、状态保存和样式 |
| `research/` | 官方正文快照及维护研究资料 |
| `research/archive/` | 历史复核台账与关系展示代码，作为维护资料保存，不进入产品页面 |

资料快照日期：2026-11-13。查询范围为五类官方列表中未标记废弃的 290 项权限。历史审查报告和 QA 记录按其记录日期保存。
